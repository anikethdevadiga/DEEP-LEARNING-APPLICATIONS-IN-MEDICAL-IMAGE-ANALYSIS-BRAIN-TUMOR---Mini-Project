# DEEP-LEARNING-APPLICATIONS-IN-MEDICAL-IMAGE-ANALYSIS-BRAIN-TUMOR
– Designed a CNN-based model to detect brain tumors from MRI images with 96% accuracy using transfer learning.
– Used OpenCV and NumPy for image preprocessing, including resizing, normalization, and augmentation.
– Trained and evaluated the model on medical datasets to ensure high reliability and precision.
– Demonstrated practical application of deep learning in healthcare diagnostics.
